# FinScope

FinTech-прототип для одного сценария. Пользователь загружает выписку и выясняет, куда ушли деньги и какие операции повлияли на расходы.

## Запуск

Откройте `dist/index.html` в браузере. Приложение сразу покажет вымышленную выписку в тенге за июнь–октябрь 2026 года. Установка зависимостей и ключ API не требуются. Для запуска через HTTP выполните `node preview.cjs` в каталоге проекта и откройте адрес, который выведет команда.

## Страницы

- `#overview` — расходы за месяц, главные категории, последние операции и статус проверки.
- `#transactions` — поиск, фильтры по категории, сумме, дате и статусу проверки, сортировка и экспорт результата в CSV.
- `#quality` — очередь совпадений, фильтры по типу и статусу, решения по строкам.
- `#analytics` — динамика по дням и неделям, структура расходов, изменения между месяцами и сигналы.
- `#budget` — план и фактические расходы по месячным лимитам. Лимиты сохраняются отдельно для месяца и валюты.
- `#archive` — поиск и повторное открытие сохранённых CSV, включая решения по дублям.
- `#assistant` — диалог с расчётами по открытой выписке и переходами к доказательствам.
- `#prices` — график, таблица и ссылки на публикации БНС.

В октябрьском примере FinScope показывает рост расходов на кафе и доставку, выделяет нетипичную сумму за наушники и находит четыре повторяющихся платежа. Нажмите на вывод, чтобы увидеть связанные операции или детали платежа.

На графике «Рост и снижение расходов» можно выбрать месяц и раскрыть операции по категории, которая сильнее всего повлияла на изменение. Панель «Инфляция в Казахстане» показывает опубликованную месячную и годовую инфляцию за январь–октябрь 2026 года. У каждой точки есть ссылка и дата публикации Бюро национальной статистики.

## Своя выписка

Пример формата есть в `dist/example.csv`. Принимаются CSV в UTF-8 и Windows-1251 с запятыми, точками с запятой или табуляцией. Нужны дата, описание и сумма. Вместо суммы можно указать отдельные поля списания и зачисления. Основные заголовки понимаются по-русски и по-английски, например `Дата операции`, `Описание`, `Списание`, `Зачисление` или `date`, `description`, `debit`, `credit`. Форматы даты — `YYYY-MM-DD` и `DD.MM.YYYY`, время операции допускается.

- `currency` — одна валюта на файл. Если колонки нет, используется значение из окна загрузки (по умолчанию KZT).
- `direction` — `out` для расхода, `in` для поступления и `transfer` для перевода между своими счетами. Знак сумм для строк без направления можно выбрать при загрузке. В режиме «Автоматически» при наличии отрицательных сумм без направления они считаются расходами. Если отрицательных сумм без направления нет, расходами считаются положительные суммы без направления.
- `category` — необязательная готовая категория. Поддерживаются коды `grocery`, `shopping`, `dining`, `transport`, `bills`, `health`, `other` и их русские названия из интерфейса.

Приложение обрабатывает выписку в браузере. База IndexedDB `finscope-ledger` версии 1 хранит импортированные операции, список сохранённых выписок, решения по дублям и указатель на текущую выписку. После перезагрузки она откроется снова. Вкладка «Архив» открывает сохранённые выписки и позволяет удалить ненужные записи из этого браузера. Если доступ к IndexedDB недоступен, выписку можно анализировать в памяти и статус над графиками показывает, что файл открыт без сохранения.

## Анализ

Локальный наивный байесовский классификатор обучается на 60 размеченных примерах. Категорию из файла можно передать напрямую. При малом различии между оценками модель оставляет операцию в категории «Другое». В деталях операции видны слова, которые повлияли на выбор.

Сравнение использует предыдущий календарный месяц. Границы выписки определяются по датам её первой и последней операции, включая поступления. Если один из месяцев неполный, FinScope сравнивает только общие числа. Если пересечения нет или в файле нет операций за предыдущий месяц, сравнение недоступно. Нетипичные суммы определяются относительно медианы и медианного абсолютного отклонения по категории. Повторяющиеся платежи сопоставляются по описанию, близким сумме и дню месяца.

ИИ-помощник использует отдельный классификатор запросов. Он определяет тип вопроса и вызывает расчёт по текущей выписке или читает опубликованные показатели. Попробуйте «Сравни июль и октябрь», «А по транспорту?» или «Что изменилось после проверки дублей?». При наличии непроверенных совпадений ответы с расходами помечаются как предварительные. Смена источника и сохранение решения по дублям обновляют контекст диалога.

## Проверка дублей

Откройте «Показать пример с дублем» под заголовком дашборда или загрузите свой файл. FinScope группирует строки с одинаковым номером операции, учитывая номер счёта, если он указан. Несовпадающие реквизиты при одинаковом номере выделяются отдельно. Без номера операции проверяются совпадения даты, записанного в CSV времени, описания, суммы и направления. Строки с разными заполненными номерами и операции в разные дни по одному описанию и сумме не считаются дублями.

В окне проверки указаны физические номера строк CSV и суммы до и после решения. До сохранения все строки участвуют в расчётах. Снимите отметки с подтверждённых дублей или сохраните все строки. Любую отметку можно вернуть через «Решения по строкам». Решения по сохранённому импорту восстанавливаются из архива. Проверка работает внутри одной выписки и опирается на её реквизиты.

Запустите `node --test`, чтобы воспроизвести проверки импорта, совпадений, пересчёта и ответов помощника.
